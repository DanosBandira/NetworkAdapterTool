Put programs and scripts for profile commands here:
- Windows: .exe, .ps1, .bat, .cmd
- Linux: .sh (run with bash), or .ps1 when PowerShell 7 (pwsh) is installed

A command with only a file name, e.g. "tool.exe" or "mount_share.sh", is
looked up in this folder; a full path such as "C:\Tools\tool.exe" or
"/opt/tools/start.sh" is used as is.

beckhoff-auto-router.ps1 is a PowerShell script for Windows.

Keep this folder when you update the app.
